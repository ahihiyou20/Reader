# Reader prototype

`reader-demo.html` is a clickable prototype of the feed, Details and Comments & Apply views, used to compare the visual style with the reference app. It is written as an Artifact page body (no `<!doctype>`/`<head>` wrapper), so open it through the published artifact, or wrap it in a minimal HTML document to view it locally.

It follows `docs/03-ui-ux-style-guide.md`: spring physics with momentum projection and velocity handoff, rubber-banding, section focus/dim, highlight and citation chips, the KEY POINT card, EN/VI switching and the mobile-native baseline. The background art is placeholder SVG, not imagery from the reference app.
